# 通用踩坑清单

|触发/症状|证据检查|处理|不能做|
|---|---|---|---|
|bitfile_name正确但IP缺失|加载后的overlay.ip_dict与HWH实例是否相同|安全停止应用；检查可信发布清单；显式加载正确Overlay|忽略元数据访问猜测地址|
|版本不符|契约expected与只读寄存器结果|停；检查软件/bit版本|用旧版本硬跑新寄存器|
|缺hwh/hash不同|manifest及同名文件|重新取得成对构建物|重新给不明文件生成hash冒充可信|
|等待done超时|状态/错误码、时钟/复位、启动语义|保存状态并停止；按IP手册排查|无限wait或自动重复启动|
|寄存器读取后值消失|read-to-clear/FIFO pop契约|明确副作用及快照方式|全寄存器扫描|
|符号/倍数错|signed、scale、单位与黄金向量|先边界测试再查业务模型|把结果拟合目标值|
|换板加载失败|器件、IO、时钟、板卡镜像/PYNQ版本|为新板重新构建与实测|同一bit跨板通用|
|UART掉字节|FIFO深度、波特率、状态、线程调度|降低负载或改善接收结构；重发完整帧|忽略RX错误/接受残帧|
|DMA没done|TLAST、TKEEP、长度、通道、时钟复位|按DMA文档检查与安全停机|声称本包已实现DMA封装|

DMA/cache仅给出未来排查方向，不属于本次已实现或验证的功能。UART示例来源是16byte FIFO在115200/8N1下约1.39ms填满，轮询间隔不是实时调度保证；这不是所有UART的通用固定阈值。
