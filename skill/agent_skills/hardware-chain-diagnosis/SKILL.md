# 硬件链路分层诊断

## 工作流程
1. 先关闭激励和机械驱动，确认供电、电平和测点；不运行附件中的危险示例。询问不能从资料确认的实际接线，不用AR名称猜排针。
2. 检查实际加载Overlay及IP身份；download=False只读元数据，不是编程PL。核对地址和允许访问的寄存器。
3. 仅在已确认、授权的安全RW寄存器做回读测试；禁止遍历未知MMIO地址写值，有副作用的读也不可盲扫。
4. 在板卡端、连接器端、芯片端区分测点。静态高低证明连线/电平，不证明边沿数。
5. 回解片选有效期间的逐边沿帧；读事务、配置事务、dummy/pipeline语义分别验证。万用表慢速测试不替代示波器协议证据。
6. 用两个已知模拟输入检查码值斜率和偏置，分辨量程未配置、位移和增益错误；不先放宽有效门限掩盖问题。
7. 每步给出预期、相反结果和下一步；遇过流、过压、发热或动作不可控立即停止，不能靠软件finally代替急停。

## 使用与输出
读 [案例及边界](references/case.md) 判断是否与当前场景相符。输出使用 [报告模板](assets/report.md)。缺少用户独占事实时一次询问最阻塞的问题；不要把历史工程参数迁到新板。

用户请求示例：请用此流程只读审查提供的工程，给出可复现证据、风险及下一项最有区分力的测试。
