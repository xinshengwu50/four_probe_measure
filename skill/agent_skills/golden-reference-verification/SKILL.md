# 黄金参考与反证验证

## 工作流程
1. 明确被验证对象、物理假设、单位和允许误差；旧输出兼容性与物理正确性分开报告。
2. 黄金结果独立推导，不调用被测算法生成期望。必要时用两条独立数值路线、极限、维度/尺度与对称性检查。
3. 区分电压增益、电流标定、几何模型和接触变化；保存标定条件。已包含0.990V标定时不得再次乘0.99，不为进入参考区间拟合系数。
4. 用未参与标定的负载/输入做留出验证；由同一ADC电压反推的电流可能吸收ADC增益误差。
5. 验证测试实际执行到结尾、异常退出非0。故意破坏关键位宽/互锁/握手确认断言失败；在隔离副本做mutation，不破坏用户工程。
6. 数字插值先插值标量再映射颜色，测点精确、场有界、空/单点/常量/非有限值都要测试；插值不是连续实测。
7. 报告RAW_OBSERVATION、OFFLINE_TEST、RTL_SIM、BUILD、BOARD、HYPOTHESIS等级、来源版本及尚未验证范围。

## 使用与输出
读 [案例及边界](references/case.md) 判断是否与当前场景相符。输出使用 [报告模板](assets/report.md)。缺少用户独占事实时一次询问最阻塞的问题；不要把历史工程参数迁到新板。

用户请求示例：请用此流程只读审查提供的工程，给出可复现证据、风险及下一项最有区分力的测试。
