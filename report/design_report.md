# 当前架构

本版本职责是PS扫描/模型/人机交互与PL确定时序执行协作，不把所有任务搬入FPGA。

PS接收屏端参数，校验授权，规划R/X/Z扫描，配置FP_DSP，解释正反结果，进行材料/几何计算和质量检查，回填页面并保存CSV/JSON历史。核心流程在Python模块，不只存在Notebook单元格中。

ALL_Final通过AXI提供ADC采样、前端量程/极性/电流、电机执行和安全寄存器。复位/看门狗和限位/互锁优先于普通运动，复位后保持，禁止自动回零。

FP_DSPv5旁听真实SPI采样并通过AXI控制ALL_Final：FULL/VERIFY/FORCED、基本判稳、一对正反积分、累加统计。无直方图/频谱/拟合/波形。调度拥有者冲突必须报错，PS不得在PL测量时私自写模拟控制。

单点/9点/25点每点数据立即回填，扫描完成后保存结果。当前热力图是离散位置示意，非连续图像；颜色是本次结果的相对范围。报告是最后有效点，不能当作均匀性统计。

测量物理模型及校准适用性不由RTL仿真证明。没有独立电流采样，不得把校准表值称为每点实测电流。真实压力和温湿度传感均未实现。
