# ADC RTL

当前 M2 已包含独立 SPI 主控、单次采样控制器和 AXI4-Lite 寄存器包装层。
AXI 与采样共用一条时钟，包装层只锁存/读取原始 32 位 SPI 帧，不在 PL 中
解释 ADS8681 的模拟量程或材料公式。

重写约束：

- SPI 帧宽、位序、CPOL/CPHA、时钟分频和超时必须参数化。
- 原始 ADC 帧只负责采集和锁存；电压单位换算、材料公式和标定由
  `sw/pynq` 黄金模型先定义，再映射到 AXI 寄存器。
- `ads8681_axi_lite.sv` 的控制写入按 bit0 使能、bit1 启动脉冲、bit2 清错脉冲
  解释；结果有效位在 AXI 状态寄存器中粘滞到下一次启动。
- 每个可综合模块必须先有独立 testbench，覆盖复位、边界码值、超时和错误恢复。
- 在 ADS8681 实物信息确认前，不把旧工程的电压缩放常量写死进 RTL。
