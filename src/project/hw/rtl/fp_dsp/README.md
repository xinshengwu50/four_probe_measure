# FP_DSP v5

FP_DSP listens to the actual ADS8681 SPI frame stream and controls ALL_Final through an AXI-Lite master restricted to that peripheral. PS configures physical thresholds in native ADC units, calibrated per-polarity currents in nA and time intervals in ms.

FULL pilots enabled ranges; VERIFY checks the locked range and falls back to FULL if needed; FORCED uses the requested enabled range. Formal acquisition is exactly one forward window followed by one reverse window. The BASIC mean-comparison stability test remains. There is no repeatedABBA sequence, histogram, spectral engine, exponential fit or waveform recorder.

ID0x46504431; VERSION5; CAPS0x417. Registers0x000..0x0DC configure/control and0x100..0x1FC return selected range, pilot and aggregate statistics. Word0x074 is fixed pair_mode=1, not a repeat count. Former diagnostic ranges read zero; capability bits are absent. Oldversion4 drivers/bitstreams must not be mixed.

ADC delta means are signedQ8 codes; aggregate sums/counts are native codes; thresholds are codes; ratios useQ16; time is milliseconds. PS usesLSB=5.12/32768V/code, no extra gain. Both current and sense polarity reverse together, so Vf=If*R+E, Vr=Ir*R-E and R=(Vf+Vr)/(If+Ir). Do not blindly negateVr or takeabs to manufacture valid results.

Reset/watchdog checks, ownership conflict, ADC no-sample and AXI timeout errors remain. Every exit requests currentOFF throughALL_Final; that controller retains final authority. No mechanical motion is generated byFP_DSP.

Sources are listed in fp_dsp_sources.f. Self-checking end-to-end tests are tb_fp_dsp.sv; arithmetic and state decisions also have Python golden tests. Test results and routed resource/timing metrics are in report/verification.md. No physical-board validation is implied.
